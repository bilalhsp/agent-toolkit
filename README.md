# Agent Toolkit 🤖

A personal collection of reusable AI agent skills, instructions, and workflows for coding, research, and development.

## 📁 Structure

- `AGENTS.md` — Global instructions and coding guidelines.
- `skills/` — Reusable skills for AI coding agents.
- `LICENSE` — MIT License.

## ⚙️ Usage

Clone the repository:

```bash
git clone https://github.com/bilalhsp/agent-toolkit.git
```

Skills and instructions can be integrated with compatible AI coding agents, including OpenAI Codex.

# Pi SDK integration

### Choose the SDK surface

Embed `@earendil-works/pi-coding-agent` in Node.js or Bun when the app needs
Pi's resource discovery, session management, and compaction. A non-JavaScript
host can drive Pi over RPC if it needs to keep its current language. Code
generated by the agent can target any language, independently of the host.
Check the package's installed declarations, lockfile, runtime engine, and
matching SDK examples before using a method or option. [Pi SDK](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/sdk.md) · [Pi RPC](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/rpc.md)

### Load only the app's resources

- Pair a server-selected working directory and app-owned agent directory with
  `DefaultResourceLoader`. Supply the profile's base or appended prompt and its
  skill root. Current SDK releases support explicit `additionalSkillPaths` with
  ambient discovery disabled through `noSkills`. Check that behavior on the
  pinned release. Reload before creating a session and surface discovery
  diagnostics. Disable ambient extensions, prompt templates, and project
  context when the profile does not use them. [Resource loader source](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/src/core/resource-loader.ts) · [Skills example](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/examples/sdk/04-skills.ts)
- Register the required tools and set an explicit allowlist. SDK defaults can
  expose general read, edit, write, and shell tools. Keep app-provided tool
  references and any server-side credentials outside model-visible output.
  [SDK configuration](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/sdk.md#configuring-a-session)
- Check skill advertisement in the effective system prompt as well as discovery
  in the loader. The current prompt builder looks for a tool named `read` or
  `bash` before including the skills section. For a scoped app, a custom
  `read` can serve discovered skill files and bundled text resources. Verify
  that the custom tool overrides the built-in on the pinned SDK. Resolve real
  paths, reject escapes including symlinks, and cap reads. A discovered skill's
  name or path grants no permissions by itself. [Prompt builder](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/src/core/system-prompt.ts) · [Tool registry](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/src/core/agent-session.ts)

Use normal Pi prompt composition so that skill metadata remains available.
A skill describes when it applies in the frontmatter and loads detailed
instructions only when selected. Bundle documentation with its source,
version, and exact relative paths. Keep application tools explicit when a
copied skill depends on scripts or external services.
[Pi skills](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/skills.md) · [Agent Skills specification](https://agentskills.io/specification)

### Wire the lifecycle

- **On configuration**, resolve the registered profile and its provider/model
  through Pi's model runtime. Use the host's secret configuration, load
  resources once for that profile configuration, and surface discovery errors
  before admitting runs. The app owns the profile's model defaults and limits.
- **On invocation**, resolve the user or job's access, assemble its scoped
  tool handlers, and select the session manager. Supply the configured model,
  loaded resources, and explicit active tool names to `createAgentSession`.
  Check the actual option names and behavior on the pinned SDK.
- **On settlement**, return the validated tool submission or the permitted
  assistant text for this request. Propagate cancellation and dispose of the
  session and any run-local clients. A durable worker promotes only the
  checkpoint and output it owns.

### Run and verify

Use `createAgentSession` with an in-memory session manager for stateless
requests or a persisted manager for conversation and job resumption. Await the
prompt, return finalized output, and dispose of the session in `finally`.
Pass cancellation from the applicable owner, such as the HTTP request or job
worker. Keep mutable per-run tool state separate across concurrent requests.
[Session lifecycle and events](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/sdk.md#session-management)

For structured results, a typed submission tool can validate and capture the
artifact while normal assistant text carries explanations or questions. Verify
the full path with an SDK session where practical. Check both a permitted
skill read and a denied out-of-scope read. Keep provider credentials and raw
upstream errors out of user-facing responses.
